# Studio Layers · 原生图层导入
在 Figma 桌面端打开可编辑的 Design 文件，选择 Plugins → Development → Import plugin from manifest，选择本目录 manifest.json。运行插件，选择导入包中的 figma-import.json，再点击创建原生图层。

v0.5 插件兼容 studio-reconstruction/2、studio-reconstruction/1 和旧 studio-standard/2。新包必须使用本次随附插件，旧版不会读取矢量路径。创建新画板，不修改现有设计；失败移除本次创建的画板。文字为独立 Text，图形路径为可编辑 Vector（M/L/Q/C/Z），矩形/椭圆为原生形状，照片为图片填充。原图对照层隐藏且锁定，清底图片层锁定，可自行解锁。长图切片保持原像素坐标，每片≤4096px，画板尺寸不缩小。

新包没有原生文字或图形时拒绝导入，避免把位图误报为转换成功。插件分别报告文字和矢量图形数量。照片内部不自动矢量化，不能恢复原始设计图层、被遮挡背景或精确字体。照片上的文字清底为近似修补，可能损失局部纹理。字体缺失时会替换并提示，请在 Figma 再次核对原文、换行、基线、清底与所有图层。

插件完全离线，不发送图片和密钥；输出并非 .fig 文件。工作台验证使用模拟插件宿主，真实编辑器仍需人工视觉验收。
