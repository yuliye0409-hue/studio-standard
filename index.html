继续在 Figma 中编辑

  1. 下载并解压导入包。
  2. 在 Figma 桌面端，通过「Plugins → Development → Import plugin from manifest」选择包内插件的 manifest.json。
  3. 运行插件，选择包内的 figma-import.json。会创建新画板，不覆盖已有设计。
请使用本次 ZIP 内的 v0.5 插件（旧版不支持矢量路径）。文字是 TEXT，图形是 VECTOR/基础形状，照片是图片层。原图隐藏锁定供对照。

这不是 .fig 源文件。字体缺失时插件会提示替换，导入后请核对字体与换行。

如何得到可编辑结果

  1. 上传图片，设置视觉模型并确认分析。也可手动画出文字区域，填写原文。
  2. 检查候选图层的原文、范围、颜色与字体。文字与图形分别成为原生图层。无法核对的候选请调整或关闭；照片保留为图片。
  3. 切换原图与重建视图，确认没有遗漏、重影与换行变化。逐图勾选确认。
  4. 下载导入包，通过随附的离线插件创建 Figma 图层。

无法从任意扁平图片恢复原始图层、被遮挡背景或精确字体。照片上的文字会按掩膜清理，并近似修补背景；纹理、光影与精确字体仍需人工复核。
